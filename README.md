# carrerlaunch

A responsive, front-end opportunity discovery website built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `CareerLaunch` folder in VS Code.
3. Open `index.html`.
4. If you have the VS Code **Live Server** extension, right-click `index.html` and choose **Open with Live Server**.
5. Otherwise, double-click `index.html` to open it in your browser.

## Included
- Responsive landing page
- Opportunity cards with sample data
- Search by title, organisation, category or description
- Category filters and sorting
- Save/unsave interaction (browser session only)
- Demo login/signup modal
- Demo newsletter form

## Important
This is a front-end prototype. Login, signup, newsletter subscriptions, saved opportunities across devices, organiser submissions and real applications are not connected to a backend. The sample opportunity listings and dates are illustrative, not verified live events. Replace them with verified information before publishing.

## Files
- `index.html` — page structure
- `style.css` — visual design and responsive layout
- `script.js` — sample data and interactions
